Run it locally

The dashboard runs on your machine, on your Earth Engine account

M‑MES pulls real satellite imagery through your own registered Google Earth Engine project. That means it can't run inside a static web page — but it takes about five minutes to get live on your laptop.

Why not just embed it here? Earth Engine requires per-user OAuth authentication and a registered Cloud project (free, mandatory since November 2024). There's no way to run that flow inside a hosted static page without asking you to hand over credentials to a third party — so the honest answer is: run it yourself, it's genuinely quick.

1Clone and set up the environment

git clone <your-repo-url>
cd manganese-prospectivity
conda env create -f environment.yml
conda activate manganese-prospectivity

2Register an Earth Engine project (once, free)

Go to code.earthengine.google.com/register, register a new Cloud project as "Unpaid usage → noncommercial/research," and copy the project ID. Every teammate needs their own — it's per-account, not shared quota.

3Point the scripts at your project

Set EE_PROJECT in fetch_landsat_gee.py and shortfall_model.py to your project ID.

4Run the pipeline, then the app

python src/data_acquisition/fetch_landsat_gee.py
python src/modeling/train_baseline_rf.py
streamlit run app/streamlit_app.py

First run opens a browser window for Earth Engine authentication — one-time per machine.

5Run the on-demand AOI tool

The upgraded app includes a "Run on this AOI" panel that calls gee_feature_pipeline.py live against any bounding box you draw — the closest thing to real-time band-ratio screening this pipeline can honestly offer. See README.md for the AOI-tool section.
